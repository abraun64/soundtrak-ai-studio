Deployment guide

First — the thing that makes this different: you own it. What you're setting up here isn't a website you log into or an app you rent. It's a copy of Soundtrak's whole AI Studio that lives on your computer:
  • You own it — yours to run indefinitely, no seat licence, no lock-in.
  • It's all readable — how it works, your brand profile, and every asset it makes are plain files you can open, read, and change.
  • You run and control it — the AI does the work; you make the calls, and steer it in plain English.
  • Your data stays yours — on your machine; the only thing that leaves is what you type into a session.
It's a premium, licensed product — yours to run for your own business's marketing, not to resell or run for other people's clients. Transparent and yours to control, not open-source.

Get your own copy running on your computer. No coding, and no experience with Claude needed. A few quick installs, then the system sets itself up — about 30–45 minutes, most of it waiting on downloads.

Never used Claude before? Read this first. Your system runs inside Claude Code — an AI assistant that lives on your computer. You use it by typing plain‑English requests (like messaging a very capable colleague); it does the work and shows you — you never write code yourself. Three things to know up front:
  • You'll need a Claude subscription — a Claude Pro or Max plan (the same account that runs Claude.ai). It isn't free.
  • You'll use the Claude Code desktop app (or the terminal). The browser version won't work — more on that in Step 2.
  • Before it ever changes a file or runs anything, it shows you and asks permission. Nothing happens without your OK.
This guide installs everything once. After that, you just chat.
Don't want to do the setup yourself? Whoever gave you this system can do steps 1–4 for you on a screen-share in about half an hour. You only ever need the chat (step 4 onward).
Step 1 — Install Python

This runs the system's behind-the-scenes scripts.

  1. Go to python.org/downloads and click the big yellow Download Python button.
  2. Open the file you just downloaded.
  3. IMPORTANT: on the first screen, tick "Add Python to PATH" (bottom of the window) before clicking Install Now. This one tick prevents the most common setup problem.
  4. Let it finish, then click Close.
On a Mac or Linux? The system's behind‑the‑scenes engine calls the command python (not python3). Many Macs and Linux machines only have python3 — and if so, the auto‑update and backup silently won't run. You don't need to fix this by hand now: the setup check in Step 4 tests for it and, if it's missing, prints the exact one‑line fix (usually pointing python at python3, or using a virtual environment). Windows users can ignore this — ticking "Add Python to PATH" above already sorts it.
Step 2 — Install Claude Code & sign in

Claude Code is the app you'll actually use — the AI you type your requests to.

⚠️ Use the desktop app (or the terminal) — not the browser version. The web / browser version of Claude runs in the cloud and cannot open the folder on your computer or run the studio's files, so it will not work for this. You need the Claude Code desktop app (or the terminal CLI), which runs on your own machine. Install that below.
  1. Get a Claude account first. You need a paid plan — Claude Pro or Max (the same login as Claude.ai). If you don't have one, sign up at claude.com/pricing.
  2. Install the Claude Code desktop app using Anthropic's official guide: code.claude.com/docs/en/setup. (Again — the browser version won't run the studio; install the app.)
  3. Do the 5‑minute quickstart — it shows a first‑timer exactly what to click: code.claude.com/docs/en/quickstart. The first time you open Claude Code it opens your browser to log in — sign in with your Pro/Max account. You only do this once.
Step 3 — Download the Soundtrak AI Studio from GitHub

The whole Studio is one folder of files, hosted on GitHub. You don't need a GitHub account — anyone can download it.

  1. Open github.com/abraun64/soundtrak-ai-marketing-system.
  2. Click the green < > Code button (top‑right of the file list), then Download ZIP.
  3. The ZIP saves into your Downloads folder. Right‑click it → Extract All… → Extract.
  4. Move the extracted folder into your OneDrive (or Dropbox) folder, then rename it Marketing AI System. This step matters: keeping it inside OneDrive/Dropbox gives you an automatic offsite backup of everything you do, with no extra setup.
Where it should end up: something like C:\Users\<you>\OneDrive\Marketing AI System. That one folder is your system — everything lives inside it.
Step 4 — Open your system in Claude Code and set it up

Claude Code always works inside one folder. You point it at your Marketing AI System folder, then run one command to finish the install.

  1. Open the Claude desktop app, then click </> Code to open Claude Code.
  2. Press + New to start a chat session.
  3. Open the Marketing AI System folder as your project — choose Open folder and pick the folder you extracted in Step 3. (Terminal version instead? Open a terminal inside that folder and run claude.) You're in the right place when Claude Code shows Marketing AI System as the current project/folder.
  4. In the chat, type: set yourself up. It installs the last few pieces, checks everything works, and turns on automatic backup. If something's missing it tells you the one thing to fix, in plain language. When it says READY, setup is done. (One time only.)
How you "talk to it": type your request in the box at the bottom and press Enter. It replies and gets to work. Type / on its own to see the list of built‑in commands and skills (that's what something like /system-manager is — you pick it from that list). Whenever it wants to change a file or run something, it shows you first and asks — approve it and it carries on. Nothing happens without your OK.
What it's installing: two small helper libraries (markdown and pyyaml) that the system needs, plus one optional extra (playwright) used only to make preview thumbnail images in the gallery — campaigns run fine without it, so don't worry if that one shows a yellow warning. If you'd rather install them yourself, the three are listed in the requirements.txt file in your system folder and go in with one command, pip install -r requirements.txt — but you don't have to: "set yourself up" does it for you.
One‑time licence agreement: the first time, setup shows you the licence and disclaimer and asks you to agree before it continues. The system is free for your own business use and is provided "as is", entirely at your own risk (full terms are in the LICENSE file). The assistant will show you the terms and ask you to reply I AGREE — do that once and it carries on.
Step 5 — Set up your working chats

Now set up the chats you'll use day to day. For each, press + New and make sure it's using the Marketing AI System folder you just set up.

  1. Improve the system — this chat is to make the system itself better and improve how it operates (it is not for running a campaign). Type "/system-manager" to set it up. Nothing is required from you on Day 0, but from here you can say "run a system retro", "capture an idea: …", or "add to backlog: …". This is how the system gets better over time — your ideas become tracked work you can pick up later.
  2. Brand setup — do this once, before you run a campaign. This foundation is the knowledge base every campaign reuses, so you never re‑explain yourself. It collects things like your style guide, tone of voice, governance rules, target market and tech stack. Type "Brand setup" and the system interviews you and builds your foundation. Have these ready to paste in or describe:
    • Brand style guide — or just your logo, colours and fonts; even favourite pages of your website can do.
    • Tone of voice — how you sound, words you use and words you avoid.
    • Positioning & segments — what you stand for, and who you're selling to.
    • Rules you must follow — only if you're regulated (finance, health, government…): disclaimers, things you can't claim.
    • Where you publish + your martech — your key marketing channels, plus your tech tools (CRM, email, analytics). If any needs a password or key, the system shows you where to enter it safely — never in a file.
    • Best-practice examples — a few standout marketing campaigns or pieces for the system to learn from.
The one habit that matters: a fresh chat for each new job — each campaign, each system retrospective — and give it a name you'll remember. Everything you do is saved automatically and carried across chats through your foundation, so a new chat never loses your brand or your past work.
Step 6 — Bookmark your two dashboards

Everything you review happens on two HTML pages you open in your browser. Bookmark both now so they're one click away (on Chrome, save them to your Bookmarks Bar).

  1. Campaign Dashboard — in File Explorer, open your Marketing AI System folder → the campaigns folder → double‑click index.html. It's at something like C:\Users\<you>\OneDrive\Marketing AI System\campaigns\index.html. It opens the All Campaigns page in your browser — bookmark it. (It's empty until you start your first campaign — that's expected.)
  2. System Improvements Dashboard — in File Explorer, open your Marketing AI System folder → the system folder → double‑click dashboard.html. It's at something like C:\Users\<you>\OneDrive\Marketing AI System\system\dashboard.html. It opens your System backlog (ideas and improvements) — bookmark it too.
Why bookmark them? These pages are how you see everything — where each campaign stands, what's waiting for your approval, and the running list of system ideas. They update themselves as you work; you just refresh.
Step 7 — (Optional, Windows only) Make the gallery's file buttons open natively

When you review a campaign in the asset gallery, each asset has two convenience buttons — 📁 Open folder and ✏️ Edit copy — that jump you straight to that asset's files.

  • On Mac and Linux these already work — they open in your file manager. Nothing to do; skip this step.
  • On Windows they need a quick one‑time permission before they'll open File Explorer / your text editor. Until you grant it, those two buttons just don't do anything.

This is optional — you can always reach an asset's files the normal way (open the campaign folder in File Explorer). But if you want the buttons live on Windows, paste this into your Claude Code chat (it'll ask before running) — or run it in a terminal inside your project folder:

powershell -ExecutionPolicy Bypass -File ".\.claude\skills\asset-gallery\protocol\setup-protocol.ps1"

It needs no admin rights, auto‑detects your folder (nothing to edit), and is fully reversible — the how‑to‑undo and full detail are in .claude/skills/asset-gallery/protocol/setup-cookbook.md.

Step 8 — Your first campaign

That's it — you're set up. You're now ready for your first campaign: press + New (name it for the campaign, e.g. "Q3 launch") and type "start a campaign: <what it's for>". The Operator guide walks you through it, stage by stage.

If the health check flags something

Step 4 ("set yourself up") runs a "doctor" that checks your setup. A red [FAIL] line is a real blocker and always prints the exact fix; a yellow [WARN] line is just a heads‑up you can usually ignore. The usual ones:

LineWhat it meansFix
[FAIL] python module: … MISSINGa required helper library (markdown / pyyaml) didn't installtype "set yourself up" again — it retries
"python is not recognised" (Windows)Python installed without "Add to PATH"re-run the Step 1 installer and tick "Add Python to PATH"
[FAIL] `python` NOT on PATH (only `python3`) (Mac/Linux)the engine's python command is missing, so auto‑update & backup won't runpoint python at python3 — the doctor prints the exact one‑line command — or use a virtual environment
[WARN] playwright … (optional)the thumbnail‑image tool isn't installed — not a blockerignore it, or say "set yourself up" to add it; it only affects gallery preview images
[WARN] git (recommended…)Git isn't installed — not a blocker; you just lose version historyoptional; install Git if you want version history + online backup (see below)

Do I need a GitHub account?

No — not to download the system, and not to use it day to day. GitHub shows up in two separate ways, and only the optional one needs an account of your own:

GitHub touchpointWhose it isAccount needed?
The public page you download from (Step 3)the people who make the systemNo — anyone can download
An optional online backup of your own workyours (a free private repo)Yes — but only if you want it

Backup & upgrades (the short version)

  • Backup is automatic once set up (Step 4): your work saves at the end of every session. The safety net is that local save plus your OneDrive/Dropbox folder — an offsite copy with zero extra setup. That's enough for most people, no GitHub account required.
  • Git is recommended, not required. If Git is installed, the system keeps a full version history of your work and can push to an online backup; if it isn't, the studio still runs perfectly and your OneDrive/Dropbox folder is your backup. The setup check flags a missing Git as a yellow "recommended" warning, never a blocker — it's your call whether to install it.
  • Want a separate online backup in your own account? Optional — install Git, create a free private repo, then say "set yourself up" again and the system connects it.
  • Upgrades: your copy is yours and keeps working as-is — you never have to upgrade. If a newer version is released, whoever gave you the system can hand you the update.
